# Conversion Optimization

> Princípios de otimização de conversão para landing pages.

---

## 1. Anatomia da Landing Page

| Seção | Propósito | Elementos |
|-------|-----------|-----------|
| **Hero** | Capturar atenção | Headline, subheadline, CTA, visual |
| **Problema** | Gerar identificação | Dor do cliente, sintomas |
| **Solução** | Apresentar resposta | Seu produto/serviço |
| **Benefícios** | Mostrar valor | 3-5 benefícios claros |
| **Prova Social** | Gerar confiança | Depoimentos, logos, números |
| **CTA** | Converter | Botão + urgência |
| **FAQ** | Eliminar objeções | 5-8 perguntas |

---

## 2. Above-the-Fold

**O que o usuário DEVE ver em 3 segundos:**

| Elemento | Regra |
|----------|-------|
| Headline | Benefício principal, < 10 palavras |
| Subheadline | Expandir promessa, < 25 palavras |
| CTA | Cor contrastante, texto com benefício |
| Visual | Produto ou resultado, não genérico |
| Prova rápida | "500+ clientes" ou logo de empresa |

---

## 3. CTAs que Convertem

### Anatomia do CTA

```
[Verbo de Ação] + [Benefício] + [Urgência]
```

### Exemplos

| ❌ Fraco | ✅ Forte |
|----------|----------|
| Enviar | Quero meu e-book grátis |
| Comprar | Começar minha transformação |
| Clique aqui | Garantir minha vaga agora |

### Cores de CTA

| Cor | Quando Usar |
|-----|-------------|
| **Verde** | Ação positiva, gratuito |
| **Laranja** | Urgência, destaque |
| **Azul** | Confiança, corporativo |
| **Vermelho** | Escassez, oferta limitada |

## 5. Formulários

### Regras de Ouro

| Regra | Motivo |
|-------|--------|
| **Mínimo de campos** | Cada campo = -10% conversão |
| **Pedir email primeiro** | Campo de menor fricção |
| **Labels acima do campo** | Mais legível em mobile |
| **Botão com benefício** | Não use "Enviar" |
| **Privacy assurance** | "Não enviamos spam" |

### Campos por Estágio

| Estágio do Funil | Campos Recomendados |
|------------------|---------------------|
| **Topo** (lead magnet) | Email apenas |
| **Meio** (trial) | Email + Nome |
| **Fundo** (venda) | Email + Nome + Telefone |

---

## 6. Urgência e Escassez

### Tipos Legítimos

| Tipo | Exemplo |
|------|---------|
| **Tempo** | "Oferta válida até sexta" |
| **Quantidade** | "Últimas 5 vagas" |
| **Bônus** | "Bônus só para os 50 primeiros" |
| **Preço** | "Preço sobe amanhã" |

### ⚠️ Anti-Patterns

- ❌ Countdown que reseta
- ❌ "Últimas vagas" permanente
- ❌ Escassez falsa

---

## 7. Trust Signals

| Elemento | Onde Usar |
|----------|-----------|
| **Selos de segurança** | Próximo ao formulário |
| **Garantia** | Próximo ao CTA |
| **Certificações** | Footer ou seção dedicada |
| **Política de privacidade** | Link no formulário |
| **SSL/HTTPS** | Obrigatório |

---

## 8. Mobile Optimization

| Elemento | Regra Mobile |
|----------|--------------|
| **CTA** | Min 48x48px, thumb-friendly |
| **Formulário** | Input grande, teclado correto |
| **Hero** | Stack vertical, headline primeiro |
| **Scroll** | Evite horizontal |
| **Loading** | < 3s obrigatório |

---

## 9. A/B Testing Priorities

### O que Testar Primeiro

| Prioridade | Elemento | Impacto |
|------------|----------|---------|
| 1 | Headline | Alto |
| 2 | CTA (texto + cor) | Alto |
| 3 | Hero visual | Médio |
| 4 | Prova social | Médio |
| 5 | Layout | Baixo |

### Regras de Teste

- Testar UMA variável por vez
- Mínimo 100 conversões por variação
- Significância estatística > 95%
- Rodar por pelo menos 7 dias

---

## 10. Métricas de Conversão

| Métrica | Benchmark | Ação se Baixo |
|---------|-----------|---------------|
| **Conversion Rate** | 2-5% | Revisar CTA + headline |
| **Bounce Rate** | < 40% | Melhorar above-the-fold |
| **Time on Page** | > 2min | Mais conteúdo engajador |
| **Scroll Depth** | > 60% | Melhorar hierarquia |
| **Form Abandonment** | < 50% | Reduzir campos |

---

> **Lembre-se:** Conversão = Desejo - Fricção. Aumente desejo, reduza fricção.
